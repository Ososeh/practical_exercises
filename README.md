# React Practical Exercises

One Vite and React project containing all five classroom exercises from the
State and Events module.

## Exercises

1. Like Button - number state and functional updates
2. Password Visibility - controlled input and boolean state
3. Login Status - conditional rendering
4. Product Cart Counter - multiple event handlers and state limits
5. Student List - arrays, objects, keys, immutable updates, and derived totals

The navigation displays one exercise at a time while keeping all exercise
components mounted. This preserves each exercise's local state when the user
switches between them.

## Run the project

```bash
npm install
npm run dev
```

Open the address shown in the terminal, normally `http://localhost:5173/`.

## Quality checks

```bash
npm run lint
npm run build
```

## Source comments

Purposeful comments explain state, controlled inputs, events, functional
updates, conditional rendering, list rendering, props, immutable array
operations, keys, derived values, accessibility, navigation, and responsive
styling. Obvious markup is intentionally not over-commented.
